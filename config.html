The Loop

1. Open one of the editors above. It auto-loads its CSVs or JSON from this same folder.

2. Edit visually. Drag pins, tick checkboxes, set thresholds, align images.

3. Publish from the editor. It downloads the updated file to your computer.

4. Upload that file back into this GitHub repo, replacing the old one. The live map updates.

Publish writes a file. Uploading that file is what makes it live.
If something goes wrong, you can always ?resetpassport to clear a tester's progress, or use git revert.
