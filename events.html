Events

An event is a saved copy of the site's data (and, if you want, its photos) kept in events/event-name/ in your repository. Applying an event copies it over the live site, so visitors see that event's markers, spots, passport, and settings. Each event also gets its own link (Demo2.html?event=name), and events you mark for the switcher appear in the About panel on the map so guests can move between them. GitHub copies files it already has, so nothing is uploaded and nothing is stored twice.
